# Mishra Clinic — Landing Page

A responsive, single-page clinic website built with vanilla HTML, CSS, and JavaScript.

## 🚀 How to Use

1. Open `index.html` in a browser — that's it. No build tools required.
2. To deploy, upload the entire folder to any static host (Hostinger, Netlify, Vercel, GitHub Pages).

## 🎨 How to Rebrand for a New Client

**You only need to edit ONE file: `js/config.js`**

Change the values in `CLINIC_CONFIG` (clinic name, doctor name, phone, email, address, timings, services) and the entire site updates automatically.

Optional: Edit `css/variables.css` to change the color theme.
